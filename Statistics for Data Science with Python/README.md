# Statistics for Data Science with Python

## Title: Boston Housing

**Statistics for Data Science with Python** forms a fundamental pillar of the Data Science curriculum, bridging the gap between raw data analysis, mathematical rigor, and actionable business insights using Python.

The project demonstrates the ability to test statistical hypotheses.

---

## Core Objectives

1. **Descriptive Data Analysis:** Learn to summarize, visualize, and interpret the underlying characteristics of a dataset using central tendency, dispersion, and distribution shapes.
2. **Probability & Distributions:** Understand the theoretical distributions (e.g., Normal, Binomial, Poisson) that model real-world data behaviors and form the basis of predictive analytics.
3. **Hypothesis Testing:** Formulate and execute structured statistical tests to validate assumptions, assess correlations, and back business decisions with mathematical proof.
4. **Regression Modeling:** Implement and interpret linear and multi-variable regression models to understand relationships between features and forecast continuous outcomes.
5. **Statistical Computing:** Transition from theoretical formulas to programmatic execution by writing efficient, reproducible statistical code in Python.

---

## Technical Skills & Tooling

### 1. Programming & Libraries
* **Python 3.x:** Core language used for all statistical modeling and computations.
* **Pandas & NumPy:** For robust data manipulation, structured data cleaning, vectorization, and matrix operations.
* **SciPy (`scipy.stats`):** Used for advanced scientific computations, generating probability distributions, and conducting statistical tests.
* **Statsmodels:** Utilized for exploring data, estimating statistical models, and performing structural regression analysis.
* **Matplotlib & Seaborn:** For generating clean, publication-grade statistical visualizations (e.g., Boxplots, Histograms, QQ-plots, Scatter plots with regression lines).

### 2. Statistical Methodologies
* **Descriptive Statistics:** Mean, Median, Mode, Variance, Standard Deviation, Interquartile Range (IQR), and Skewness.
* **Inferential Statistics:** * **T-Tests:** One-sample, Independent two-sample, and Paired T-tests.
  * **ANOVA (Analysis of Variance):** Testing differences between three or more categorical group means.
  * **Chi-Square Tests:** For testing independence/association between categorical variables.
  * **Correlation Analysis:** Pearson and Spearman rank correlation coefficients.
* **Regression:** Ordinary Least Squares (OLS) Linear Regression, residual analysis, and evaluating model fit metrics ($R^2$, Adjusted $R^2$, $p$-values).
